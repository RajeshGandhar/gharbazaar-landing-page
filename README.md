# GharBazaar Landing

Build a premium, production-ready landing page for my Indian real-estate marketplace called “GharBazaar”.

IMPORTANT:

Use the attached/reference homepage design as the visual direction. Do NOT copy another website pixel-for-pixel. Take inspiration from modern Indian property platforms such as 99acres, MagicBricks and Housing.com, but create an original GharBazaar identity.

The website should NOT look AI-generated, template-like, overly futuristic, or full of generic glassmorphism cards.

The goal is:

“GharBazaar — a premium, simple and trustworthy place to Buy, Rent, Discover and Post Properties in India.”

==================================================

1. OVERALL DESIGN DIRECTION

==================================================

Create a premium modern real-estate marketplace.

Visual feeling:

- Premium

- Trustworthy

- Modern

- Clean

- Sophisticated

- Indian real-estate focused

- Conversion-oriented

- Fast and simple

- Similar quality level to a serious established property marketplace

Avoid:

- Excessive gradients

- Excessive glassmorphism

- Floating random cards everywhere

- Neon colors

- Huge rounded cards

- Excessive shadows

- Cartoon illustrations

- Generic AI-looking UI

- Overuse of animations

- 3D gimmicks

The UI should feel closer to Apple-level product polish combined with the simplicity and usability of a leading Indian property portal.

Use a subtle permanent dark theme.

DO NOT add a light/dark theme toggle.

The dark theme should not be pitch black.

Use:

- Deep navy / charcoal background

- Off-white text

- Muted gray secondary text

- Warm premium orange/gold as the primary CTA/accent

- Subtle blue-gray surfaces

Keep contrast excellent and accessibility-friendly.

18. DATA ARCHITECTURE

==================================================

For the first version, use realistic mock/demo property data.

But structure the data so it can later connect directly to Supabase.

Example property object:

{

  id,

  title,

  propertyType,

  listingType,

  price,

  city,

  locality,

  bedrooms,

  bathrooms,

  area,

  furnishing,

  images,

  verified,

  featured

}

Do not hardcode property information throughout JSX.

Keep demo data centralized.

==================================================

19. SUPABASE COMPATIBILITY

==================================================

IMPORTANT:

Do not break the existing Supabase authentication or database architecture.

Do not replace Supabase.

Do not create a second backend.

Do not modify authentication unless absolutely necessary.

The landing page should be compatible with the existing GharBazaar Supabase architecture.

Property data should be designed so that mock data can later be replaced by Supabase queries without redesigning the UI.

3. Trust
